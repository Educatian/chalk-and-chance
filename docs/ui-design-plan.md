# Chalk & Chance: UI·아트 디자인 계획 (전면 재설계)

작성 2026-11-21 · 브랜치 `Educatian/ui-design-overhaul` (feel-implementation 위에 쌓음) · 이 문서만 보고 바로 구현할 수 있을 만큼 구체적으로 썼다.

## 0. 결론 먼저

**방향: 현재 아트를 유지하지 않고 월드 아트와 UI 키트를 전부 새로 만든다.** 단, 학생 초상화(감정 12종 × 10명)는 새 팔레트로 재매핑하고 새 액자에 넣어 살린다. 새로 그리는 비용(유료 생성)이 들기 때문이며, 새로 그릴지는 오너 결정 사항이다(§9).

| # | 핵심 결정 | 이유 (레퍼런스 근거는 §1) |
|---|---|---|
| 1 | **월드는 1 텍셀 = 2 기준 px, 하나의 밀도로 통일.** 타일 16 텍셀(=32 px), 학생 16×24, 교사 16×28, 책상 16×12 텍셀. 960×540 기준에서 1080p는 정확히 4 화면 px/텍셀이다. | 레퍼런스 9개 모두 월드 전체가 단일 텍셀 밀도다. 현재 문제(학생, 바닥, 교사가 서로 다른 밀도)의 근본 해결이다. |
| 2 | **교실은 "무대", UI는 무대 밖.** 방(24×13 타일 = 768×416 px)을 화면 중앙에 두고 HUD는 위·아래 띠와 좌우 여백에 둔다. 앞벽 2타일에 칠판이 늘 보인다. | Stardew, Moonlighter, Potion Permit은 HUD를 화면 가장자리에 소수만 고정하고 월드를 가리지 않는다. 지금은 HUD 띠가 칠판을 가린다. |
| 3 | **UI 프레임 키트는 3종뿐.** ① 칠판(어두운 초록-검정, HUD·대화·인카운터) ② 종이 카드(밝은 크림, 브리핑·결과·문서) ③ 버튼 알약(상태 5종). 모두 2 px 픽셀 테두리를 쓰는 nine-slice다. | 좋은 레퍼런스는 프레임 스타일이 2~3개로 적고 역할이 분명하다(Undertale 1종, Stardew 2종, Papers Please는 문서와 책상). |
| 4 | **글꼴은 2개, 크기는 5단계만.** 픽셀 서체 Pixelify Sans(OFL)는 제목과 숫자에만, 작은 라벨·이름·본문은 매끈한 산세리프(Godot 기본)를 쓴다(리뷰 반영). 최소 12 px(960 기준). | 텍스트가 많은 게임(Coffee Talk, Potion Permit)은 본문 가독성을 지킨다. 픽셀 서체는 표지판·숫자에만 써서 정체성을 준다. 현재 PressStart2P는 읽기 어렵다. |
| 5 | **상태는 색 + 모양 + 단어로 표시한다.** 맞음은 초록 + ✓ 칩 + "LANDED", 이름은 파랑 + 시계 칩 + "TOO EARLY", 아직 아님은 코랄 + 가로선 칩 + "NOT YET", 중립은 회색이다. 포커스는 노란 2 px 링이다. | 색만으로 구분하지 않는다(색각 이상 대응). 정직한 피드백 원칙도 유지한다: 오답에 축하 연출을 쓰지 않는다. |

**제작 방식:** 픽셀 아트를 **코드로 작성한다**(`tools/art/` Python + Pillow, 32색 고정 팔레트). 스프라이트는 텍스트 격자로 그리고, 캐릭터는 부품(몸·머리·옷·피부톤)을 조합하며, 외곽선과 음영은 규칙으로 자동 적용한다. 그래서 모든 캐릭터·타일·프레임이 같은 팔레트·같은 외곽선·같은 광원(좌상단)을 갖고 재현 가능하다(`python tools/art/build_art.py`). 비용은 0이다. 초상화를 새로 만들려면 이미지 생성(유료 크레딧)이 필요하므로 **쓰기 전에 오너에게 묻는다.**

**버티컬 슬라이스 먼저:** 교실 1개(교사, 학생, 책상, 칠판, HUD)와 인카운터 화면 1개를 새 스타일로 만들고, 스크린샷을 오너에게 보낸 뒤 나머지 화면으로 확장한다.

### 1.1 공통 원칙 → 이 게임에 적용

| 원칙 | 레퍼런스 공통점 | Chalk & Chance 적용 |

| P2 캐릭터는 1.5~2타일 높이, 문은 캐릭터보다 높다 | Stardew 2타일, 대부분 1.5~2 | 학생 1.5(24 텍셀), 교사 1.75(28), 문 2타일(16×32) |
| P3 HUD는 적고, 가장자리에 고정, 월드를 가리지 않는다 | Stardew, Moonlighter | 상시 HUD는 주의·침착·시간 3개만, 나머지는 열 때만 |

| P8 판정은 물리적 착지감 | Papers Please 도장 | 결과 화면 랭크 도장 유지, 턴 칩 착지 |

**레퍼런스끼리 다른 점과 선택:**
- 초상 대 말풍선: Potion Permit과 Eastward는 말풍선, Stardew와 Coffee Talk는 초상이다. **초상을 택한다.** 이 게임의 학습 핵심은 학생의 표정(12감정)을 읽는 것이기 때문이다.
- 픽셀 UI 대 고해상 UI: Cassette Beasts는 혼합해 비판을 받았고, Undertale은 순수 픽셀이다. **프레임은 픽셀(2 px 그리드)로, 본문 글자만 매끈하게** 간다. 문장이 길어 픽셀 서체로는 피로하기 때문이다.

## 2. 아트 디렉션 결정

| 항목 | 결정 | 현재 대비 왜 나은가 |
|---|---|---|
| 시점 | 탑다운 3/4 유지 | 교실 순회(근접 관리)가 핵심 동사라 방 전체가 보여야 한다 |
| 픽셀 스케일 | 16 텍셀 타일, ×2 → 32 px (960×540 기준) | 지금은 32 텍셀 타일 ×1.25(비정수)에 캐릭터와 교사가 서로 다른 밀도다 |
| 캐릭터 비율 | 학생 16×24(머리 9, 몸 15, 3등신 반), 교사 16×28(4등신, 학생보다 확실히 큼) | 지금은 교사(56 텍셀)가 학생(60)보다 작은 그림이다 |
| 팔레트 | 32색 고정(§3.3) | 지금은 생성형 초상 수천 색과 타일 수십 색이 섞여 있다 |
| 방 구성 | 24×13 논리 격자 유지(좌석과 근접 규칙 불변), 앞벽 2타일 + 칠판, 측벽 책장·사물함·창, 앞쪽 러그, 교사 책상 | 빈 벽돌 바닥 "강당" 느낌을 가구·벽 장식과 바닥 구역으로 채운다 |
| 화면 구성 | 방 768×416 중앙, HUD는 위(56) 아래(56) 띠, 좌우 여백 96은 목표·코치 패널 | 지금은 HUD 띠가 앞벽과 칠판을 가린다 |
| UI 키트 | 칠판·종이·버튼 3종 nine-slice | 지금은 StyleBoxFlat 둥근 사각형에 색이 화면마다 다르다 |
| 초상 | 기존 128 px 초상을 32색 팔레트로 재매핑해 새 액자에 넣는다(무료). 새 생성은 오너 승인 후 | 12감정 × 10명 = 120장을 코드로 다시 그리는 것은 품질 기준에 못 미친다 |

**방 크기에 대한 솔직한 한계:** 24×13 격자는 좌석과 근접(PROX_TILES=3) 규칙의 기반이다. 방을 줄이면 교사가 한 번에 더 많은 학생을 덮어 드리프트 난이도가 바뀐다. 이번에는 **격자를 유지하고 가구와 구역으로 밀도를 만든다.** 방 축소는 균형 변경이므로 오너 결정 사항이다(§9).

## 3. 스타일 가이드

### 3.1 해상도와 스케일링
- 기준 해상도 960×540, stretch `canvas_items` + `expand`(PR #3에서 도입). 월드는 정수배(1 텍셀 = 2 px), UI는 같은 2 px 그리드에 맞춘다.
- 화면 배율 정책: 1080p는 정확히 ×2(텍셀당 4 화면 px), 2160p는 ×4로 정수다. 720p와 임의 웹 창은 소수배이며 nearest 필터로 감수한다(문서화된 한계).
- 모든 월드 텍스처는 `TEXTURE_FILTER_NEAREST`, 위치는 정수 px로 스냅한다.

### 3.2 그리드와 간격 토큰(960 기준 px)

## 4. 화면별 재설계

모든 화면은 공통 규칙을 따른다: 프레임 3종, 서체 2종, 간격 토큰, 상태 언어.

### 4.1 교실(오버월드) — 플레이 시간 1순위
```
┌──────────────────────────── 960 ────────────────────────────┐
│[칠판 띠 56] 👁 주의 ▓▓▓▓░  ♥ 침착 ▓▓▓░  ⏱ 1:57   방해 0  참여 2/6 │
├─────96─────┬──────────── 방 768×416 ───────────┬─────96─────┤
│ 목표 카드   │ ▒앞벽 2타일: 문 │창│ 칠 판 │창│ 시계 ▒ │ 코치 Vee  │
│ (O로 펼침)  │ 교사책상  러그                          │ 초상 48px │
│ ✓ 주의≥65  │   [책상][책상]  [책상][책상]            │ 한 줄 힌트│
│ ○ 모두 발언 │    학생   학생    학생   학생            │           │
│            │  (이름은 책상 아래, 드리프트 바는 머리 위) │           │
│            │ 책장 │                          │ 사물함  │           │
├────────────┴──────────────────────────────────┴───────────┤
│[칠판 띠 56] Z 말하기: Jordan   |  방 상태: 안정               │
└──────────────────────────────────────────────────────────────┘
```
- 바뀌는 것: HUD가 방 밖으로 나가 칠판이 보인다(P3). 좌우 여백이 목표·코치 자리가 된다. 바닥은 나무판 + 앞쪽 러그 + 통로 구역이다.
- 학생: 의자에 앉은 포즈(16×24, 다리가 책상에 가림), 책상 16×12 텍셀이 학생 앞에 놓인다. 이름은 Label 서체 12, 책상 아래, z 최상위. 드리프트 바는 16×2 텍셀로 머리 위 2텍셀 간격.
- 좌석과 근접: 격자와 좌표는 그대로다(§2 한계).

### 4.2 1:1 인카운터 — 2순위
```
┌───────────────────────────────────────────────┐
│ [종이 탭] ENCOUNTER · Jordan        ⏱ 대기 ▓▓░ │
│ ┌──────────────┐  ┌───── frame_board ───────┐ │
│ │  초상 128→   │  │ 몰입 ▓▓▓  질서 ▓▓▓▓      │ │
│ │  192 액자     │  │ 신뢰 ▓▓   침착 ▓▓▓▓▓     │ │
│ │  (감정 12)    │  │ 유대 ▓                   │ │
│ └──────────────┘  └──────────────────────────┘ │
│ ┌──────── frame_board 대사 ───────────────────┐ │
│ │ Jordan: "45가 5보다 큰데 왜 0.45가 작아?"     │ │
│ └─────────────────────────────────────────────┘ │
│ [칩 LANDED ✓] 결과 한 줄 · 코치 한 줄            │
│ [1 Elicit][2 Extend][3 Revoice][4 Tell] [Type] │
│ [5 Praise][6 Connect][7 Redirect][8 Wait]      │
└───────────────────────────────────────────────┘
```
- 초상을 왼쪽 큰 액자로 옮긴다(P7, 표정 읽기가 핵심). 미터는 오른쪽 칠판 패널, 대사는 넓은 칠판 박스, move는 버튼 키트로 만든다.

### 4.3 렉처 / 짐(gym)
- 인카운터와 같은 3단 구조. 위는 미터(칠판), 가운데는 학생 초상 줄(각 64 px 액자, 선택 학생은 노란 링), 아래는 대사 박스 + move 버튼.
- 짐은 학생별 이해도·불안 미니바를 초상 액자 아래에 붙인다.

### 4.4 인터럽트·리플렉션 카드
- `frame_board` 카드, 본문 높이에 맞춤(PR #3), 선택지는 버튼 키트, 상단에 아이콘(문 두드림 등 8×8).

### 4.5 결과(세션 완료·디브리프)
- `frame_paper` 문서. 왼쪽 위 Display 제목, 오른쪽 위 랭크 도장(PR #3 모션 유지). 증거 바는 종이 위 연필 바(종이 선 색 + 상태색). 하단에 "다음 연습" 한 줄과 버튼 2개.

### 4.6 허브(미션 선택)
```
┌ 칠판 띠: CHALK & CHANCE   Lv 2 ▓▓▓░ XP   [설정] ┐
│ [Evidence][Upgrade][Profile][Items][Board]       │
│ ┌ frame_paper 미션 카드 ┐  ← 선택 카드만 크게      │
│ │ 썸네일 │ 제목 Title18 │ 상태칩 NEXT/OPEN/LOCK  │
│ │        │ 한 줄 요약 Body │ 보상 Label           │
│ └────────┴──────────────┴──────────[Start]┘      │
│ 나머지 카드는 접힌 한 줄 목록                       │
└───────────────────────────────────────────────────┘
```
- 지금의 상단 6줄 메타 정보를 칩 한 줄로 줄이고, 포커스된 카드만 펼친다(정보 밀도 원칙).

### 4.7 타이틀 / 로그인 / 가져오기·미리보기
- 타이틀: 새 교실 일러스트 대신 **새 타일과 스프라이트로 구성한 교실 장면**(새 아트 재사용)과 로고(Pixelify Display), 오른쪽에 종이 패널(데모 시작, 반 코드 로그인).
- 가져오기와 미리보기: `frame_paper` 문서 하나, 입력칸은 버튼 키트의 inset 변형.

### 4.8 코치 카드·시네마틱·설정
- 코치 카드: `frame_board` + Vee 초상 64 액자.
- 시네마틱: 레터박스 + 하단 `frame_board` 자막. 배경 일러스트는 기존 백드롭을 팔레트 재매핑한다.
- 설정: `frame_paper` 목록, 토글은 버튼 키트.

## 5. 교실 상세 (현대 교실로 개정, 2026-11-21 오너 피드백 반영)

**오너 피드백:** 나무 마루·책장 교실이 구식이다. 한국·미국의 현대 교실을 근거로 다시 그린다.

**결정:** 기본은 **미국 현대 교실**이다. 수업이 grade 5 분수·소수이고, 학생 이름(Jordan, Priya, Mei-Lin, Deshawn, Diego)이 미국 학교를 가리키기 때문이다. 코드 파이프라인에서는 변형 비용이 작아 **한국 교실 변형**도 만들었다(설정 "Classroom look: US / Korea"). 격자 24×13, 좌석, 근접 규칙, 텍셀 밀도는 그대로다.

### 5.1 근거(조사) → 반영
| 요소 | 근거 | 미국(기본) | 한국 변형 |

| 벽·빛 | 창 쪽 블라인드·냉난방, 게시판, 수납함(관찰) | 한쪽 벽: 블라인드 창 + 에어컨, 다른 쪽: 색 테두리 게시판·수납 bins·낮은 책장(독서 코너)·싱크 | 커튼 창, 공기청정기, 뒤쪽 개인 사물함, 청소 도구 코너, 게시판 |
| 기타 | — | 시계 + 방송 스피커, 화분, 바닥에 떨어진 학습지, 빈 책상의 의자, 가방 | 동일 |

### 5.2 고정값
| 항목 | 값 |
|---|---|
| 방 | 24×13 타일(16 텍셀) → 768×416 px, 화면 중앙, HUD는 방 밖 |
| 앞벽 | 1×2타일 벽면을 방 위 한 칸에 그림. 보드 6타일(x 9~14), 문, 시계·스피커, 앵커차트(미국) |
| 좌석 연출 | 좌석 블록 안쪽 러그, 빈 책상에는 의자, 일부 책상 옆 가방(통행 불가 타일 없음) |
| 학생 | 16×24, 7프레임(기본·숨쉬기·좌·우·손들기·고개숙임·눈깜빡임). 드리프트 상태에 따라 focused/restless/drifting 루프, 교사가 바라보면 손들기 |
| 이름·말풍선·드리프트 바 | 이름은 책상 아래, 바는 머리 위, 말풍선은 어깨 오른쪽. 서로 겹치지 않는 고정 슬롯 |
| 서체 역할 | 픽셀 서체는 제목과 숫자(18 px 이상)에만, 작은 라벨·이름·힌트는 매끈한 서체 |
| 카메라 | 고정(방 전체가 늘 보임) |

### 5.3 팔레트 확장
현대 재료를 위해 15색을 추가했다: 벽 페인트 `#f4f1ea`, 천장 `#d9dde2`, 타일 `#eeece6` `#dcd8d0` `#c3beb4`, 알루미늄 `#aab0b8` `#6f7781`, 화면 `#1f2b3b`, 화이트보드 `#fbfbf7`, 메이플 `#efd9b0` `#e2c48f` `#c7a46c`, 청록 카펫 `#5fb1b6`, 코르크 `#c79a6a`, 사물함 `#8fa6bd`. 전체 팔레트는 기본 35 + 초상 8 + 교실 15 = 58색이며, `tools/art/palette.py`가 유일한 출처다.

### 5.4 초상 리매핑
첫 시도(전역 팔레트로 강제 양자화)는 얼굴이 뭉개졌다. 두 번째 시도(모드 필터)는 눈이 지워졌다. 채택한 방식은 초상마다 28색 팔레트를 뽑고 각 색을 전역 팔레트 쪽으로 35% 당기는 것이다(디더 없음, 64 텍셀 = 2 px 그리드). 배경은 파란 그라데이션만 따라가는 플러드 필로 지우므로 남색·보라 옷은 남는다. 비교: `docs/ui-overhaul/slice2/10_portrait_remap_before_after.jpg`.
