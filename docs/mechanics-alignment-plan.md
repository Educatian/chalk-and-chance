## 0. 결론 먼저

**진단:** 손맛 작업(턴 비트, 칩, 단축키)은 "고른 move의 결과"를 잘 보여준다. 그런데 이 게임이 연습시키려는 기술 가운데 절반은 **선택만 하고 수행하지 않는다.**

| 기술 | 지금 | 판정 |
|---|---|---|
| 기다림(Wait time, Rowe 1986) | 바가 저절로 차고 UI가 "3초 기다려"라고 말한다. 가만히 있으면 성공이다 | **약함** — 절제(restraint)를 *하는* 느낌이 없다 |
| 알아차림(Noticing, Jacobs 2010) | HUD가 "Hot spot: Talia 70%"처럼 누가 흐트러지는지 말해 준다 | **어긋남** — 게임이 대신 알아차린다 |
| 끌어내기 → 확장 → 되말하기(순서) | PathJudge가 순서를 판정한다(이르면 "too early") | **정렬됨** — 순서가 곧 교수법이다 |
| 말해주기 억제 | Tell은 절대 맞지 않고 참여도가 떨어진다 | **정렬됨** |
| 피드백의 *종류*(Hattie & Timperley 2007) | Praise 버튼 하나뿐(구체적/일반적 구분 없음) | **빠짐** |
| 최소 개입 재지시(Simonsen 2008) | 인터럽트 카드에서 근접 대 공개 지적을 고른다. 정답이 뻔하고 시계가 멈춘다 | **약함** |
| 순회·근접(위딧니스) | 근접하면 드리프트가 줄고, 칠판을 보면 늘어난다 | **정렬됨**, 다만 효과가 손에 안 느껴진다 |
| 공평한 참여 | "모든 학생이 한 번 발언" = 한 번 방문하면 체크 | **어긋남** — 기술 없이 완수된다 |
| 숙고적 연습(디브리프 → 재도전) | 요약 숫자와 성찰 선택지, 재시도는 있다. 결정적 순간 재생은 없다 | **약함** |

**가장 가치 높은 변경 5가지**
1. **(A) 생각 시간을 학생 쪽에 보이게**: 대기 바 대신 학생 초상 위 "생각 중" 말풍선이 차오른다. 3초에 "지금" 표시가 뜨고, 일찍 누르면 그 자리에서 "끊었다"가 보인다. 규칙은 같고 *느낌*이 절제로 바뀐다.
2. **(A) 디브리프에 결정적 순간 2~3개**: 내가 한 move → 학생 반응 → 왜(경로 노트) → 다음 시도 목표 하나.
3. **(A) 목표를 기술 이름 + 증거 규칙으로 표시**: 예) `[기다림] 3초 이상 기다린 뒤 3번 움직이기`. 내용 텍스트는 그대로 두고 기술 태그와 증거만 붙인다.
4. **(A) 교실에서 근접·위딧니스가 손에 느껴지게**: 가까이 가면 흐트러졌던 학생이 진정되는 작은 초록 반응, 칠판 쪽을 보면 등 뒤 학생들에게 "?" 신호.
5. **(B, 승인 필요) 알아차림을 플레이어에게 돌려주기**: 지원 수준이 낮을 때는 HUD가 이름을 대지 않는다. 학생의 자세와 애니메이션(이미 상태 연동, PR #4)으로 읽어야 한다.

## 3. 제안

### (A) 판정·점수를 바꾸지 않는 변경 — 바로 구현

| ID | 플레이어가 하는 것 | 느낌 | 가르치는 것 | 점수 | 대체하는 것 | 공수·위험 | 퇴행 전략과 막는 법 |
|---|---|---|---|---|---|---|---|
| A1 | 학생이 생각하는 동안 손을 멈춘다. 초상 위 "생각 중…" 말풍선이 3초에 걸쳐 차오르고, 다 차면 "지금" 펄스. 일찍 누르면 말풍선이 끊기는 표시와 "끊었다" | 절제, 기다림이 *학생을 위한 것* | Wait time I(Rowe) | 불변(wait_ok 그대로) | "Wait 3.0s first" 바 | 0.5일·낮음 | 그냥 3초 기다리기 = 의도한 행동이라 퇴행 아님 |

### (B) 규칙·점수·타이밍·진행·목표를 바꾸는 변경 — 오너 승인 후에만

| ID | 바뀌는 것 | 가르치는 것 | 퇴행 전략과 막는 법 |
|---|---|---|---|
| B1 | **기다림을 직접 수행:** 질문 move를 누르면 학생 생각 말풍선이 차는 동안 "기다리는 중"이 되고, 그 사이 누르면 끊긴다(WT-I). 학생이 답한 직후 1.5초 WT-II 창 추가 | Rowe WT-I/II | 항상 끝까지 기다리기 → 권장 행동. 다만 너무 길면 참여 하락(5초 초과 시 작은 감소)으로 '무한 대기'를 막는다 |
| B2 | **알아차림 단계:** move 전에 학생 상태 칩 하나(혼란/이해함/위축/산만)를 고른다. 맞으면 해당 경로 힌트 대신 증거 +1, 틀리면 경로 안내 | Jacobs 2010 | 찍기 → 정답률을 Competency `noticing`으로 기록하고, 틀리면 다음 move의 credit 보너스가 없다 |
| B3 | **피드백 종류 분리:** Praise → "구체 칭찬(무엇을 했는지)"과 "일반 칭찬". 일반 칭찬은 신뢰 소폭 +, 이해도 0 | Hattie & Timperley | 구체 칭찬 연타 → 기존 같은 move 연속 감쇠 규칙 적용 |
| B4 | **최소 개입 사다리:** 인터럽트 카드 선택지를 근접/비언어/짧은 말/공개 지적 4단으로. 낮은 단계가 통하면 보너스, 시계는 카드 중에도 2초 흐름 | Simonsen 2008 | 항상 최저 단계 → 상황에 따라 최저 단계가 통하지 않는 카드(이미 데이터에 있는 경우)에서 비용 |
| B5 | **HUD가 알아차림을 대신하지 않게:** 지원 수준 Light/None에서 "Hot spot: 이름" 문구 숨김(학생 자세만 보임) | 알아차림 | 없음(정보 감소) |
| B6 | **공평 참여 목표의 증거 바꾸기:** `engaged_min`은 방문이 아니라 *끌어내기·되말하기가 착지한* 학생 수 | 공평한 *사고* 참여 | 쉬운 학생만 → 목표가 학생 수 기준이라 막힘 |
| B7 | **숙달 기반 해금:** 다음 미션은 배지 + 해당 기술 Competency 추정 ≥ 60%, n ≥ 3일 때 열림 | 숙달 학습 | 반복 farming → 같은 move 감쇠 + n은 *다른 학생*에서 온 관찰만 |
| B8 | **재시도 목표 고정:** 디브리프의 "다음 시도 목표"를 다음 시도의 목표 1번으로 자동 추가(달성 시 XP 보너스) | 숙고적 연습 | — |

## 4. 구현 순서
1. A1 → A3 → A4 → A2 → A5. 각각 헤드리스 체크와 오프스크린 스크린샷으로 확인한다.
2. (B)는 승인된 항목만, 각자 별도 커밋으로. 텔레메트리 이벤트(`noticing`, `wait_hold`, `redirect_tier`)를 추가한다.

## 5. 사람이 플레이해야 판단할 수 있는 것
- A1 말풍선 속도(3초)와 "지금" 펄스가 조급함을 주는지, 차분함을 주는지.
- A3 반응의 빈도가 과한지.
- B1이 승인되면 WT-II 창 길이(1.5초 제안)와 5초 초과 감소량.
